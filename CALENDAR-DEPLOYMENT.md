# Free calendar setup — GitHub Pages

The active calendar feature uses Google/Outlook event-composer links and works at https://adoblake.github.io/2DAY-APP/ after the updated source is deployed to Pages. No paid hosting, OAuth credentials, or file downloads are required.

1. After profile setup, choose whether to add your routine to an outside calendar. This is also available through Add to my calendar on Home, Day, and Profile.
2. Choose Google, personal Outlook, or work/school Outlook. Optionally select fitness days, time, and duration.
3. Open each meal/fitness button. Choose the destination calendar in the provider's editor, review, and save.
4. Google receives a prefilled repeating schedule. In Outlook, set Repeat and the journey end date before saving the first event.
5. Check that the events appear on the phone/computer where the account is enabled. Apple Calendar can show Google/Outlook accounts configured on the device.

These are editable calendar events, not a live account connection. Edit existing events in your calendar after changing your plan; reopening Add links can create duplicates. 2DAY cannot confirm that you saved an event or change one later.

Local changes are not automatically deployed to GitHub Pages. Publishing a development environment also does not update Pages. The latest source must be pushed to the repository and its Pages deployment must complete before these controls appear at the public URL.
